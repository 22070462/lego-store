# 🔧 Troubleshooting Guide

## Payment & Order Issues

### Error: "Failed to create order: Cannot read properties of undefined (reading 'order')"

**Cause**: The API response structure was not as expected, or the API_BASE URL was incorrect.

**Solution**: ✅ FIXED in v2.0.1
- Updated `cart.html` to always use `http://localhost:3000` as API_BASE
- Added response validation before accessing nested properties
- Added detailed console logging for debugging

**How to verify the fix**:
1. Open browser console (F12)
2. Try to checkout
3. Check console logs for:
   - "Creating order with items: [...]"
   - "API Response: {...}"
4. If you see these logs, the fix is working

---

### Error: "Failed to create order: Failed to fetch"

**Cause**: Backend server is not running or not accessible.

**Solutions**:

1. **Check if backend is running**:
   ```bash
   netstat -ano | findstr :3000
   ```
   Should show: `TCP    0.0.0.0:3000    ...    LISTENING`

2. **Start backend server**:
   ```bash
   cd backend
   node src/server.js
   ```

3. **Check for port conflicts**:
   - Another application might be using port 3000
   - Kill the process or change the port in `.env`

---

### Error: "Please login to checkout"

**Cause**: User is not authenticated.

**Solutions**:

1. **Login first**:
   - Go to `login.html`
   - Login with test credentials
   - Then try checkout again

2. **Check token in localStorage**:
   - Open browser console (F12)
   - Type: `localStorage.getItem('token')`
   - Should return a JWT token string
   - If null, you need to login

3. **Token expired**:
   - Tokens expire after 24 hours
   - Login again to get a new token

---

### Error: "Your cart is empty"

**Cause**: No items in cart.

**Solutions**:

1. **Add products to cart**:
   - Go to products page
   - Click "Add to Bag" on products
   - Cart badge should show item count

2. **Check cart in localStorage**:
   - Open browser console (F12)
   - Type: `JSON.parse(localStorage.getItem('cart'))`
   - Should return array of cart items

---

## Backend Issues

### Error: "Cannot find module"

**Cause**: Dependencies not installed.

**Solution**:
```bash
cd backend
npm install
```

---

### Error: "SQLITE_ERROR: no such table"

**Cause**: Database not initialized.

**Solution**:
```bash
cd backend
node src/utils/init-database.js
```

---

### Error: "Port 3000 is already in use"

**Cause**: Another process is using port 3000.

**Solutions**:

1. **Find and kill the process**:
   ```bash
   netstat -ano | findstr :3000
   taskkill /PID <PID> /F
   ```

2. **Change port**:
   - Edit `.env` file
   - Change `PORT=3000` to `PORT=3001`
   - Update `cart.html` API_BASE to match

---

## Frontend Issues

### Products not loading

**Cause**: Backend not running or API error.

**Solutions**:

1. **Check backend is running**
2. **Check browser console for errors**
3. **Test API directly**:
   - Open: `http://localhost:3000/products`
   - Should return JSON array of products

---

### Cart badge not updating

**Cause**: JavaScript error or cart not saved.

**Solutions**:

1. **Check browser console for errors**
2. **Clear localStorage and try again**:
   ```javascript
   localStorage.clear()
   location.reload()
   ```

## Common Workflows

### Fresh Start

1. Stop backend (Ctrl+C)
2. Clear browser data:
   ```javascript
   localStorage.clear()
   ```
3. Restart backend:
   ```bash
   cd backend
   node src/server.js
   ```
4. Refresh browser (Ctrl+F5)
5. Login and test

### Reset Database

1. Stop backend
2. Delete database:
   ```bash
   del backend\users.db
   ```
3. Reinitialize:
   ```bash
   cd backend
   node src\utils\init-database.js
   ```
4. Restart backend

### Check Everything

1. Backend running: `netstat -ano | findstr :3000`
2. Database exists: Check `backend\users.db` file
3. Token exists: `localStorage.getItem('token')` in console
4. Cart has items: `localStorage.getItem('cart')` in console

## Debug Checklist

When something doesn't work:

- [ ] Backend server is running
- [ ] Database file exists
- [ ] User is logged in (token in localStorage)
- [ ] Cart has items
- [ ] Browser console shows no errors
- [ ] Network tab shows successful API calls
- [ ] Correct API_BASE URL (`http://localhost:3000`)
